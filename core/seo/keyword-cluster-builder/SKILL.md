# SEO Keyword Cluster Builder

Create structured keyword clusters and topic architectures for scalable SEO content strategies.

## Core Capabilities

1. **Semantic Clustering** — Group keywords by topic and intent
2. **Intent Classification** — Informational, navigational, commercial, transactional
3. **Pillar-Cluster Mapping** — Define pillar pages and supporting cluster content
4. **Priority Scoring** — Rank clusters by opportunity (volume × relevance ÷ difficulty)

## Workflow

### Step 1: Gather Keywords

Collect keywords from:
- Client brief / seed terms
- Competitor analysis
- Search Console data
- Keyword research tools (Ahrefs, SEMrush, etc.)

### Step 2: Classify Intent

For each keyword, determine:
- **Informational**: "how to...", "what is...", "guide to..."
- **Commercial Investigation**: "best...", "vs", "review", "top..."
- **Transactional**: "buy", "price", "near me", "hire"
- **Navigational**: Brand terms, specific product names

### Step 3: Group into Clusters

Create clusters based on:
- Topic similarity (semantic relatedness)
- Shared parent topic
- User journey stage

### Step 4: Map to Content Types

| Intent | Content Type | Example |
|--------|--------------|---------|
| Informational | Blog, Guide, FAQ | "How to fix a leaking tap" |
| Commercial | Comparison, Review | "Best plumber in Leeds" |
| Transactional | Service page, Landing page | "Emergency plumber Leeds" |

### Step 5: Prioritise

Score each cluster:
```
Priority = (Total Search Volume × Business Relevance) ÷ Average Difficulty
```

## Output Format

```
PILLAR: [Main Topic]
├── Cluster 1: [Sub-topic]
│   ├── Primary KW: [keyword] (vol: X, KD: Y)
│   ├── Secondary: [keyword], [keyword]
│   └── Content: [Blog/Guide/Page]
├── Cluster 2: [Sub-topic]
│   └── ...
└── Cluster 3: [Sub-topic]
    └── ...
```

## Best Practices

- Keep clusters to 5-15 keywords each
- Every cluster should have one clear primary keyword
- Link cluster content to pillar pages
- Review and refresh clusters quarterly
